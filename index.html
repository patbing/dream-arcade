How it works

The model writes the game

openai/gpt-6.1-terra turns your words into one HTML game with a canvas, keys and a score. It also lists its keys and what each one does.

A bot plays it first

In a sandbox with no network, a bot plays a minute with no keys, holds each key, then mashes random keys, all on a fake clock with a fixed seed. It compares the pictures: a key that changes nothing is a dead key.

Problems go back to the model

If the bot finds a crash or a dead key, its findings go back to the model once for a fix. When you ask for a change later, the bot checks that nothing that worked before broke.

Like the uncle in "Fable 5.2 one-shotted my nephew's dream game", who had the model write a bot to play every stage and check the screenshots. Here the bot is ordinary code, so its verdict does not depend on the model that wrote the game.

Games run in a sandboxed frame with no network and no access to this page or your key. You pay with your own Pollen through Pollinations Connect, which keeps your key in this tab's sessionStorage. Share links carry the whole game in the link; nothing is stored on a server. Source
